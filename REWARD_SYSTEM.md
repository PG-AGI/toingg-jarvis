# Contributor Reward System

We believe great open-source contributions deserve real recognition — not just a thank-you. Toingg Jarvis runs a points-based reward program where your contributions translate directly into cash.

**1 point = ₹1 | Minimum redemption: 1,000 points (= ₹1,000)**

---

## How to Earn Points

### Code Contributions

| Contribution Type | Points |
|---|---|
| Fix a bug (small — typo, minor logic error) | 25 pts |
| Fix a bug (medium — real behavioral issue) | 75 pts |
| Fix a bug (large — platform-specific, complex) | 150 pts |
| Add a new feature (small) | 100 pts |
| Add a new feature (medium) | 250 pts |
| Add a new feature (large / requested by maintainer) | 500 pts |
| Performance improvement with measurable impact | 150 pts |
| Refactor with clear quality improvement | 100 pts |
| Add unit/integration tests | 50–150 pts |

### Documentation

| Contribution Type | Points |
|---|---|
| Fix a typo or broken link | 10 pts |
| Improve an existing section (clarity, accuracy) | 30 pts |
| Write a new guide or tutorial | 100 pts |
| Translate documentation to another language | 200 pts |
| Create a demo video or visual walkthrough | 150 pts |

### Community & Issues

| Contribution Type | Points |
|---|---|
| Report a valid bug (verified by maintainer) | 25 pts |
| Report a security vulnerability (responsibly) | 200 pts |
| Help another contributor resolve their issue | 15 pts |
| Participate meaningfully in design discussions | 10 pts |

> **Note:** Points are awarded at maintainer discretion. A contribution must be **merged or officially accepted** before points are recorded.

---

## Bonus Multipliers

| Scenario | Multiplier |
|---|---|
| First contribution to the project | 1.5× |
| Contribution fixes a `priority: high` labeled issue | 1.5× |
| Contribution adds cross-platform support | 1.25× |
| Contribution submitted within 48h of a `help wanted` label | 1.25× |

Multipliers stack — a first-time contributor fixing a high-priority bug earns 1.5 × 1.5 = **2.25×** the base points.

---

## Tracking Your Points

Your points are tracked publicly in the [Contributors Leaderboard discussion](https://github.com/PG-AGI/toingg-jarvis/discussions) (pinned in the Rewards category).

After each accepted contribution, a maintainer will:
1. Comment the awarded points on your merged PR or accepted issue.
2. Update the leaderboard.

---

## How to Redeem

Once you accumulate **1,000 or more points**:

1. Open a new issue using the [Reward Claim template](https://github.com/PG-AGI/toingg-jarvis/issues/new?template=reward_claim.yml).
2. List all contribution links and your total points.
3. Provide your preferred payment method (UPI, PayPal, or bank transfer).
4. A maintainer will verify your contributions within **7 business days** and process the payment.

> **Partial redemptions are not supported.** You must reach the 1,000-point threshold before claiming. Points beyond the threshold roll over.

---

## Rules & Fairness

- Points are non-transferable between accounts.
- Contributions must be original work — plagiarism or AI-generated filler content will be rejected without points.
- Maintainers reserve the right to adjust point values for any contribution.
- Disputes can be raised by replying to your Reward Claim issue.
- The reward program may be paused or modified with 30 days' notice posted in the Announcements discussion.
